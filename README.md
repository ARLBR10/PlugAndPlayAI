# Open WebUI Auto customization tool

> Still in development please don't put it on Production

# Why?

Well Everybody as the Knowledge that [Open WebUI](https://github.com/open-webui/open-webui) sucks on detecting which AI you are using and Add a Logo or a Name. So i made a tool that auto detect it and made it easier for API Integration on [LiteLLM](https://github.com/BerriAI/litellm) and to this customization to work fine.

# FAQ

#### Q1: Can't find my AI Provider on the Tool
Well just open an Issue at this repo and we can try to help you.

#### Q2: Whey do you need my APIs Tokens?
We just use to fetch the latest models available at your API and this data is just used on the Code and integration on LiteLLM.
